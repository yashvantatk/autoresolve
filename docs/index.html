AI proposes the fix. A failing test proves it.

AutoResolve is a Rust command-line tool that reviews Python code with AI agents and keeps only the fixes it can prove. A fix counts as proven when a generated test fails on the original code and passes after the patch, inside a locked-down Docker sandbox.

What it does for a developer


    
  
  • Create and test: fix --issue "bug report" turns a bug description into a regression test plus a candidate patch.
    • 
  
  • Review: reviewer agents find suspected bugs, and skeptic agents try to disprove each one before it goes further.
    • 
  
  • Collaborate and deploy: free scan rules output SARIF for GitHub code scanning, markdown for pull requests, and an MCP server gives AI assistants read-only access to the repo graph.
    • 
  
  • Stay in control: dry run by default, a policy file limits what a patch may touch, and apply-plan is the only step that writes to your repo.
    • 




How a fix is judged




StepDone by


Find suspected bugs, then challenge themReviewer and skeptic agents


Write a test that must fail before the patchTester agent, checked by running it


Syntax, linter, security scanner, type check, policyNon-AI checks in the sandbox


Accept or reject the patchRust code, from the gate's yes/no answers


Mark as proven or unprovenRust code: did the test go from failing to passing?





Limitations


    
  
  • "Proven" means the claimed case is fixed. It does not mean the patch is right, so read the diff.
    • 
  
  • Python only. The call graph matches functions by name only.
    • 
  
  • Small local models are unreliable for this work.
    • 
  
  • Planned, not built: pre-commit hook, log diagnosis, edge-case test generation on the same proof layer.
