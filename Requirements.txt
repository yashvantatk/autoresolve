# AutoResolve: Python-side requirements
#
# AutoResolve itself is a Rust program (Rust 1.90 or newer, edition 2024). Install the Rust
# toolchain with rustup, not with pip. Its Rust dependencies are in the Cargo.toml files and are
# fetched by `cargo build`.
#
# What pip installs here is the tooling that AutoResolve runs on the Python code it reviews:
#   - pytest   runs the generated regression tests and behavior guards
#   - ruff     syntax and error checks (E9, F rules); a patch may not increase the count
#   - bandit   security checks (medium severity and above); a patch may not increase the count
#   - mypy     type checks; a patch may not increase the count
#
# Normal use: these four are installed INSIDE the Docker sandbox image, so you do not need them on
# your machine. Build the image once:
#       docker build -t autoresolve-sandbox -f docker/sandbox.Dockerfile docker/
#       export AUTORESOLVE_DOCKER_IMAGE=autoresolve-sandbox
# docker/sandbox.Dockerfile is the source of truth for what the sandbox contains.
#
# Install this file only if you run with AUTORESOLVE_SANDBOX=local (NO isolation: generated tests
# run directly on your machine) or if you want to run the tools by hand:
#       python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt
#
# The benchmark runner (bench/run_bench.py) uses only the Python 3.10+ standard library.
#
# Versions are intentionally not pinned because the image was built from the latest releases.
# To freeze exactly what the sandbox contains, run this and paste the output over the four lines below:
#       docker run --rm --entrypoint pip autoresolve-sandbox freeze | grep -iE "^(pytest|ruff|bandit|mypy)=="
